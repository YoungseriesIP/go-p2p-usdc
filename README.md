# go-p2p-usdc

A peer-to-peer USDC payment application built on Arc.

## Goal

Build a simple app where users can:

- Connect a wallet
- Send USDC to another user
- View transaction history
- Deploy the app on Vercel

## Tech Stack

- Claude
- GitHub
- Vercel
- Arc App Kits

## Learning Journey

This repository documents my journey from beginner to building a real USDC payment application.
